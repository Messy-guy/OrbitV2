# Screenshot References for Orbit Desktop

This directory stores reference visual guides for Orbit's UI components and layouts.

### Reference Files:
- **`dashboard.jpeg`**: Overall workspace layout with header, active workspace switcher, and bottom dock.
- **`agent-grid.jpeg`**: Spatial multi-agent grid layout displaying multiple coding agents side-by-side.
- **`agent-tile.jpeg`**: Individual agent conversation tile showing provider branding, model details, live tool status, in-tile chat stream, and quick actions.
- **`share-context.jpeg`**: Context handoff modal dialog for choosing source/target agents, selecting context modules, token counts, and triggering transfers.
- **`context-panel.jpeg`**: Shared project memory panel displaying goals, % completion, architectural decisions, and open issues.
- **`activity.jpeg`**: Project-wide chronological timeline showing agent activities, file diffs, test runs, and checkpoints.
- **`sessions.jpeg`**: Agent session history viewer allowing navigation between previous conversations.

*Note: These references illustrate spatial organization and ergonomic workflows. Orbit maintains its own clean, dark-first developer aesthetic.*
